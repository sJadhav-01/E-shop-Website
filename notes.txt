> Filters in django (Custom tags and filters):


    we need to replace 'add to cart' button to increase or decrease quantity buttons. for that we are going to use 'inbuilt filters of django' 

    > creating a custom filters
    - create a folder named 'templatetags'
    - then crate a .py file 
    - import 'template' from django
    - use 'register = template.Library()' command
    - the register custom filter with name which we want to create.
        ex. 
            from django import template

            register = template.Library()
            
            @register.filter(name='is_in_cart')  # this filter is used to check if the product is present in cart or not
            def is_in_cart(product, cart):
                if cart:
                    keys = cart.keys()
                    for id in keys:
                        if int(id) == product.id:  # id(key of dict) is a string so converted into int
                            return True
                return False

    - and after creating filter we can use it on html page as below
        
        {% if product|is_in_cart:request.session.cart %}

> Middleware:

    - if we need to perform any task before handling a request, middleware comes in picture.
    - for ex. if user is trying to access orders page without logging then, its middleware's job to restrict the user from accessing it and guide user to login page and then get back to orders page.

    > creating middleware :

        def group_of_middleware(get_response):

            def middleware(request):
                response = get_response(request)
                return response

            return middleware()
    
    
    > Activationg middleware:

        - add a custom middleware in list of middleware in settings.py.
        - but if we add middleware there, then it will run everytime.
        - if we want the middleware to run for only particular action then we can import the middleware on the view file where the view is written for the particular action.

    > Applying middleware:

        - there are several ways to apply middleware.

        1. we can call middleware before view method through methode_decorator
            ex. 
                class Orders(View):

                    @method_decorator(auth_middleware)  # calling middleware through method decorator
                    def get(self, request):
                        customer = request.session.get('customer')
                        orders = Order.get_orders_by_customer(customer)

                        return render(request, 'orders.html', {'orders': orders})


        2. we can directly call a view through a middleware from urls.py  (this is a preffered way because by this we can see on which views middleware is applied in single sight)
            ex.
                urlpatterns = [
                    path('orders', auth_middleware(Orders.as_view()), name='orders')
                ]
